# API Completa — Multi Delivery

Endpoint base: `https://wzxsjxdbxonrmlmzufpv.supabase.co/functions/v1/api-completa`

A API usa `Authorization: Bearer <access_token>` nas rotas autenticadas. Rotas de catálogo são públicas.

As regras de negócio continuam nas RPCs e no RLS do banco. A API não usa service role para operações de usuário.

O contrato OpenAPI está em `openapi.json`.
